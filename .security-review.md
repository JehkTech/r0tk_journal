# R0TK Trading Journal Security Review

Date: 2026-06-04
Scope: Current local React/Vite frontend and Express/Supabase backend.

## Verified Controls

- Express mounts `helmet()` globally for HTTP security headers.
- Express mounts a global rate limiter: 100 requests per 15 minutes.
- Trade CRUD routes require bearer-token authentication.
- Trade lookup, update, delete, and screenshot upload verify ownership by `user_id`.
- Uploaded screenshots are limited to image extensions and image MIME types.
- Supabase service role usage is isolated to the backend process.
